Configuration

四级配置，逐级继承

各地区、各医院、各科室对随访的要求不同。系统的功能全部做成可勾选的模块，没有勾选的功能不会出现在首页和菜单。

层级谁来配置配置什么规则
L1地区

平台运营方

区域平台对接、方言与民族语言、地方病种方案、地方考核口径

作为本地区医院的默认值

L2医院

医院管理员（信息科、医务处）

本院功能池、渠道与接口、全院满意度与质控方案

科室只能在功能池内勾选

L3科室

科室主任、护士长

科室功能、随访方案、量表、宣教、预警阈值

默认套用推荐模板

L4个人

医生、护士

首页卡片顺序与显隐、提醒方式

只能在科室已开通范围内调整

Closed Loop

只有异常和未响应才需要人工

出院即入组，到期自动推送；全部结果汇总到质控与满意度分析，再反过来优化随访方案和模板。

OK

正常：自动归档

评分和数据在阈值内，结果写入患者档案，到期自动进入下一个随访节点，不占用医护时间。

!

异常：分级预警

红色预警即时推送责任医生手机，限时处置；超时自动升级给上级医生或科主任，处置结果必须留痕。

?

未响应：人工补访

微信和短信超时未填写，转电话或智能外呼补访；多次联系不上进入失访管理，按多位联系人继续补访。

↻

评价与改进

满意度、投诉、随访率、再入院等指标汇总到管理驾驶舱，用于质控抽检、绩效考核和优化随访方案。

Architecture

配置与模板引擎决定每家医院看到什么

配置与模板引擎按“地区 → 医院 → 科室 → 个人”逐级合成功能开关，决定每个人的首页和菜单。患者数据留在医院本地，模板中心只同步配置。

Recommendation

“最常用配置”怎么来

  • 平台运营端只统计各医院勾选了哪些功能、用了哪个模板，不涉及任何患者数据。
  • 推荐顺序：本院同科室 → 本省同类医院 → 全国同类医院 → 专家默认模板；样本不足时自动退回下一级。
  • 上线初期先用临床专家按指南编制的默认模板；接入医院越多，推荐越贴近当地习惯。
  • 关闭功能不删除数据；模板升级时医院先看差异再决定是否更新。
